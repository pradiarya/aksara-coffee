# Aksara Coffee Roastery — Company Website

A landing page for a fictional coffee roastery, built with vanilla
HTML, CSS, and JavaScript. No frameworks or build tools.

## Sections

- Hero with brand statement and CTA
- About / brand story with stats
- Product highlights (weekly coffee menu)
- Visit info + newsletter signup form

## Tech Stack

- HTML5 (semantic sections)
- CSS3 (custom properties, CSS Grid, responsive layout)
- JavaScript (form handling, validation)

## Project Structure

```
aksara-coffee/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Running Locally

No build step required. Open `index.html` directly in a browser.

## What This Demonstrates

- Semantic, accessible HTML structure
- Responsive layout with CSS Grid and media queries
- Basic form validation and UX feedback in JavaScript
- A cohesive visual identity (color, type, spacing) rather than a
  generic template
